# Security Overview

This project is designed for safe, educational, and authorized use only.

- No exploitation or fuzzing is implemented or encouraged.
- File moves are restricted to local filesystem operations initiated by the user.
- Logging is limited to local JSON files and may expose file names and paths; review logs before sharing.

## Responsible Disclosure
Please report any vulnerabilities or concerns respectfully via a GitHub issue. Provide reproduction steps and platform details where possible.
